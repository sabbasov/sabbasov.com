Monthly Archive — 5-Minute Update Process

One-time setup: Create archive/_template.html in your repo with all structure in place. Every month: duplicate it, rename, replace 5 fields, push. Vercel deploys in ~30 seconds.
# The 5 fields to replace each month (everything else stays identical) 1. <title> → "June 2025 — Rainier + Puget Sound" 2. <!-- YOUTUBE_EMBED --> → YouTube embed URL from Studio 3. <!-- PHOTO_1 --> → 2025-06_Photo_001_Summit_WEB.jpg 4. <!-- PHOTO_2 --> → 2025-06_Photo_003_Kayak_WEB.jpg 5. <!-- SUMMARY --> → 2-sentence archive text from Marketing Director # Then: git add . → git commit -m "June 2025 archive" → git push # Vercel auto-deploys. Live in ~30 seconds. Done.
Use GitHub Desktop (free, no command line needed) if you prefer a visual interface for the git push step.

AI System Setup

Two separate Claude chats. Each has a distinct role. Keep them separate — do not mix tasks between them.
Chat 1 Technical Director
Purpose: Production decisions, system questions, technical troubleshooting.

Responsible for:
  • Camera settings questions
  • DaVinci Resolve help (grading, export issues)
  • Editing structure decisions
  • Audio troubleshooting
  • Workflow refinements
Chat 2 Marketing Director
Purpose: Content planning, distribution, and all audience-facing copy. This role decides how your footage gets packaged and what content angle to lead with — not just where it gets posted.

Responsible for:
  • Content angle + story framing per month
  • YouTube titles, descriptions, tags
  • Instagram / Reels captions + hashtags
  • Website archive copy + photo alt text
  • Publishing schedule recommendation
  • Flagging if footage is light → suggesting alternatives

How to Interact with Each Chat

ChatWhat You Give ItWhat You Get Back
Technical DirectorSpecific technical problem or decision (e.g., "my D-Log M footage looks washed out after applying the LUT")Precise technical answer or corrected workflow step
Marketing DirectorThe completed BRIEF.md file pasted in full + any specific platform requirementsAll copy ready to paste: YouTube description, captions, tags, hashtags, alt text

Marketing Director — Starter System Prompt

# Paste this at the start of your Marketing Director chat — once, then reuse the chat You are the marketing director for an outdoor content creator who films hiking, kayaking, mountain biking, camping, and road trips monthly. Your role has two parts: 1. CONTENT PLANNING — given what footage exists, decide the best angle, story frame, and which clips/photos to lead with. Recommend what to highlight, not just how to describe it. 2. DISTRIBUTION — produce all copy, captions, and scheduling recommendations. Each month I send you a BRIEF in this format: MONTH · ACTIVITIES · ARC · FILM · SHORTS (up to 3) · PHOTOS (up to 10) · NOTES When I send a brief, produce in one response: 1. Recommended content angle (1 sentence — the "why watch this" frame) 2. YouTube title (under 60 chars, search-first, no hype) 3. YouTube description (150 words, timestamps placeholder) 4. 10 YouTube tags 5. One Reels caption per short — three tones: [short / medium / with hashtags] 6. Website headline (under 10 words) + 2-sentence archive summary 7. Alt text for each photo (one line each) 8. Publishing schedule (which content goes out on which day) Tone: authentic, outdoor-focused, never hype-driven. Prioritize searchability over cleverness on YouTube. If I say "minimal month" — produce only: content angle + YouTube title/desc + one Reel caption. If footage is light, suggest how to reframe it as intentional (e.g., "short solo trip" vs "failed month").

Integrations

Five integrations only. Each one earns its place. No overlap.
Google Drive
Connect: 05_EXPORTS folder only (not raw). Why: Marketing team's delivery inbox. Share folder as "View only." They pull files without you sending anything. Tool: Google Drive Desktop App.
GoPro Cloud
Connect: Auto-upload on WiFi (GoPro app → Auto Upload). Why: Unlimited original-quality raw backup included in Premium subscription. Zero cost, zero effort. This is your primary raw video backup.
GitHub + Vercel
Connect: Push monthly archive updates to GitHub → Vercel auto-deploys. One-time setup: Create archive/_template.html in your repo — this is your monthly copy-paste base. Each month: duplicate it, rename to YYYY-MM.html, replace 5 fields (title, YouTube embed URL, 3 photo filenames, summary text), commit + push. Vercel deploys in ~30 seconds. Total time: 5 minutes per month.
Meta Business Suite
Connect: Instagram + Facebook pages. Why: Free, native scheduler. Queue all Reels and photo posts for the month in one session. Direct upload, no third-party tool needed.
YouTube Studio
Connect: Channel connected to Google account. Why: Scheduled upload + chapter markers + thumbnail upload in one place. Set publish date at upload time — no external scheduler needed.
Skip: Zapier, Buffer, Hootsuite, Dropbox alongside Drive, any Adobe CC subscription. Each adds complexity without replacing something that's already free and working.
